# Get started

This tutorial starts with an empty folder and ends with a Node.js script that boots Linux, runs a
program inside it, and writes a file to its root filesystem. You need Node.js 24 or later.

To run Linux in a web page instead, follow this tutorial first, then read
[Set up a browser page](/set-up-a-browser-page/). The code is the same in both places.

## Install the packages

Create a folder and install three packages into it:

```sh
mkdir linux
cd linux
npm install @lowland/kernel @lowland/guest @lowland/image
```

Each package has one job:

- `@lowland/kernel` runs the Linux kernel and its virtual devices.
- `@lowland/guest` runs programs and works with files inside the machine.
- `@lowland/image` contains a small root filesystem with BusyBox and the apk package manager.

## Boot a machine and run a program

Save this as `linux.mjs`:

```js title="linux.mjs"
import { bootMachine } from "@lowland/kernel";
import { guestAgent } from "@lowland/guest";
import { rootImage } from "@lowland/image";

const guest = guestAgent();
const machine = await bootMachine({ cpus: 1, plugins: [rootImage(), guest] });

const uname = await guest.run(["uname", "-a"]);
console.log(new TextDecoder().decode(uname.stdout));

machine.close();
```

Run it:

```sh
node linux.mjs
```

After a few seconds, the script prints a line that starts with `Linux` and ends with
`wasm GNU/Linux`. That line was written by `uname`, running inside the machine.

The script uses three functions:

1. `guestAgent()` creates the plugin that runs programs and works with files in the machine.
2. `rootImage()` attaches the root filesystem image from `@lowland/image`.
3. `bootMachine()` starts Linux with one virtual CPU and both plugins.

`guest.run()` takes the program and its arguments as an array, waits for the program to exit,
and returns what it wrote. `stdout` holds bytes, so the script decodes them before printing.

## Change a file in the machine

The root filesystem is writable. Add these lines before `machine.close()`:

```js
await guest.fs.writeTextFile("/etc/motd", "hello from JavaScript\n");

const cat = await guest.run(["cat", "/etc/motd"]);
console.log(new TextDecoder().decode(cat.stdout));
```

Run the script again. It now also prints `hello from JavaScript`. The file was written from
JavaScript with `guest.fs` and read back by `cat` inside the machine.

Changes to the root filesystem are kept in memory. Every boot of `rootImage()` starts from the
same files, so the next run of the script does not see the file until it writes it again.
[Images](/images/) explains how to keep changes between boots.

## Shut down

`machine.close()` stops every program in the machine and releases its workers and memory. A
script that leaves the machine open does not exit.

You can also let JavaScript close the machine for you. A machine declared with `await using`
closes when the block that declares it ends:

```js
await using machine = await bootMachine({ cpus: 1, plugins: [rootImage(), guest] });
```
