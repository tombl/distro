# Access the internet

A guest reaches the outside world through a network you create with `createNetwork()`. The
network does not open connections itself. When a program in the guest connects to an address
outside the network, `createNetwork()` calls a function you provide, and that function decides
how to reach the destination.

```ts
import { createNetwork, guestAgent } from "@lowland/guest";

const network = createNetwork({ connectTcp, resolveDns });
const guest = guestAgent();
await using machine = await bootMachine({
  cpus: 1,
  plugins: [rootImage(), guest, network.attach(guest)],
});
```

The machine is set up as in the [`@lowland/guest` usage example](/reference/guest/#usage). The
rest of this page shows what to pass as `connectTcp` and `resolveDns`.

## In Node.js

Node.js can open real TCP connections, so the guest gets full network access, including TLS:

```ts
import { resolve4 } from "node:dns/promises";
import { once } from "node:events";
import { createConnection } from "node:net";
import { Duplex } from "node:stream";

const network = createNetwork({
  async connectTcp(session) {
    const socket = createConnection({
      host: session.target.hostname,
      port: session.target.port,
      signal: session.signal,
    });
    await once(socket, "connect");
    const streams = Duplex.toWeb(socket);
    await Promise.all([
      session.readable.pipeTo(streams.writable),
      streams.readable.pipeTo(session.writable),
    ]);
  },
  resolveDns: resolve4,
});
```

`connectTcp` is called once per connection and lives as long as the connection.
`session.target` is the address the guest asked for. `session.readable` and
`session.writable` carry the bytes in each direction, and `session.signal` aborts when the
connection ends.

Programs in the guest can now reach anything the Node.js process can:

```ts
await guest.run(["wget", "-qO-", "https://example.com"]);
```

To restrict access, check `session.target` and throw before reading or writing. The guest
then sees the connection refused.

## In a browser

A web page cannot open raw TCP connections. `hostFetchNetwork()` instead turns each plain
HTTP request from the guest into a `fetch()`:

```ts
import { createNetwork, hostFetchNetwork } from "@lowland/guest";

const network = createNetwork(hostFetchNetwork({ fetch: (request) => fetch(request) }));
```

This has limits that follow from what a page is allowed to do:

- Programs in the guest must use `http://` URLs. The request is sent as HTTPS. Programs that
  speak TLS themselves, such as `wget https://…`, do not work.
- Every hostname resolves to the same placeholder address. The destination is taken from the
  request's `Host` header.
- The page's own `fetch()` rules apply. Most sites do not allow cross-origin requests, so the
  browser blocks their responses.

The `fetch` function you pass decides where each request really goes. To reach sites that
block cross-origin requests, rewrite `request.url` to point at a proxy you run, and fetch that
instead.

## Other transports

`connectTcp` can use any transport that carries a byte stream, such as a WebSocket to a server
you run. Pipe `session.readable` and `session.writable` through it, as in the Node.js example.
`resolveDns` must return the IPv4 addresses for a hostname.

UDP from the guest reaches only the network's gateway. Guests use the gateway for DNS, which
`createNetwork()` answers with `resolveDns`.
