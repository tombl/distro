# Work with files

`guest.fs` works with the guest's filesystem directly from JavaScript. Changes are visible to
programs in the guest immediately, and changes made by programs are visible to `guest.fs`.

The examples on this page assume a booted machine and its `guest`, set up as in the
[`@lowland/guest` usage example](/reference/guest/#usage).

## Where you can write

The root filesystem is read-only. `/tmp` is writable and kept in memory, so its contents are
lost when the machine closes. Writing anywhere else fails with a `SystemError` whose `code` is
`"EROFS"`.

To make the whole filesystem writable, boot with a writable layer in memory on top of the
root filesystem:

```ts
await bootMachine({
  cpus: 1,
  args: ["lowland.root.overlay=tmpfs"],
  plugins: [root, guest],
});
```

## Write and read files

```ts
await guest.fs.mkdir("/tmp/project/src", { recursive: true });
await guest.fs.writeTextFile("/tmp/project/src/main.c", "int main(void) { return 0; }\n");

const source = await guest.fs.readTextFile("/tmp/project/src/main.c");
```

`writeFile()` and `readFile()` do the same with bytes. `writeFile()` also accepts a `Blob` or a
`ReadableStream`. A stream moves large data into the guest without holding all of it in
memory on the host:

```ts
const response = await fetch("https://example.com/archive.tar.gz");
await guest.fs.writeFile("/tmp/archive.tar.gz", response.body!);
```

## Make a file executable

Pass `mode` when writing, or call `chmod()` afterwards:

```ts
await guest.fs.writeTextFile("/tmp/hello.sh", "#!/bin/sh\necho hello\n", { mode: 0o755 });
await guest.run(["/tmp/hello.sh"]);
```

## List and inspect

```ts
for await (const entry of guest.fs.readDir("/tmp/project/src")) {
  console.log(entry.name, entry.isFile);
}

const info = await guest.fs.stat("/tmp/project/src/main.c");
console.log(info.size, info.mtime);
```

`stat()` rejects with code `"ENOENT"` when the path does not exist:

```ts
import { SystemError } from "@lowland/guest";

try {
  await guest.fs.stat("/tmp/maybe");
} catch (error) {
  if (!(error instanceof SystemError && error.code === "ENOENT")) throw error;
}
```

## Copy files out of the guest

Read the file and write it wherever you need it. In Node.js:

```ts
import { writeFile } from "node:fs/promises";

await writeFile("main.c", await guest.fs.readFile("/tmp/project/src/main.c"));
```

To share a whole directory instead of copying files, see
[Share a host directory](/share-a-host-directory/).

## Remove, rename, and copy

```ts
await guest.fs.rename("/tmp/a.txt", "/tmp/b.txt");
await guest.fs.copyFile("/tmp/b.txt", "/tmp/c.txt");
await guest.fs.remove("/tmp/project", { recursive: true });
```

For reading and writing at arbitrary offsets, `guest.fs.open()` returns a file handle. The
[`FileSystem` reference](/reference/guest/#FileSystem) lists every operation.
